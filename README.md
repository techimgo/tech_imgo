# 테크니컬 초등임용 데이터랩

페이지가 데이터 종류별로 분리된 GitHub Pages용 정적 사이트입니다.

- `index.html` — 메인
- `real.html` — 실제 시험 데이터
- `mock.html` — 모의고사 데이터
- `expected-2027.html` — 2027 예상
- `common.css` — 공통 네비게이션

## GitHub Pages
저장소 루트에 파일을 올린 뒤 **Settings → Pages → Deploy from a branch → main / root**를 선택하면 됩니다.

각 페이지는 상대 경로로 연결되어 있어 저장소 이름이 바뀌어도 링크가 정상적으로 작동합니다.
